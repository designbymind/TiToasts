# TiToasts examples

- `app.js`: small Classic Titanium example. Copy it into a Classic app's
  `Resources/app.js` and declare `ti.toasts` 0.5.0 in that app's `tiapp.xml`.
- `alloy/`: standalone Alloy app adapted from the AlloyTestApp toast component.
  See [the Alloy setup instructions](alloy/README.md).

Both examples are included in the module distribution ZIP.
